# Requests for comments

No standalone RFC is currently open in this directory. Candidate mechanisms in
the design corpus remain candidates until a scoped RFC is written and reviewed.

## Admission criteria

An RFC defines the problem, goals and non-goals, proposed contract, alternatives,
security and compatibility impact, rollout/recovery plan, unresolved questions,
and acceptance evidence. It is appropriate for reviewable cross-cutting work,
not an implementation diary.

## Authority and status

A draft RFC is a proposal. Acceptance must be explicit and may result in an ADR,
requirement, or specification update. Rejection or withdrawal remains visible
and carries no implementation authority.

## Naming and maintenance

Use `RFC-NNNN-short-title.md` with monotonic identifiers. Link discussion,
CarryCtx task/decision, related contracts, and final disposition. Freeze the
reviewed outcome and use a new RFC for material redesign.
