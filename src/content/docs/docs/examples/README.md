# Examples

There are no verified product examples yet. Candidate snippets from design
discussion do not belong here and must not be copied into user configurations or
plugin templates as supported code.

## Admission criteria

An example is minimal, safe, versioned, executable or mechanically validated,
and linked to the authoritative reference. It includes prerequisites, expected
result, capability/security implications, and cleanup where relevant.

## Authority and status

Examples illustrate a contract but never replace it. If an example conflicts
with reference or a normative policy, the authoritative contract wins and the
example blocks release until corrected.

## Naming and maintenance

Use a descriptive kebab-case topic and keep companion assets together only when
the format requires them. Test examples in CI once an implementation exists,
record supported versions, and remove stale examples through deprecation and
redirect review.
