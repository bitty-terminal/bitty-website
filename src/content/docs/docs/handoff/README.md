# Handoff records

This directory holds cross-session handoff records for the Bitty
repositories. A handoff is created on first use, when a CarryCtx task changes
owner before completion, and records the transferring task, the receiving
owner, the current state, and the next steps. The directory holds no records
yet; this index makes the shared top-level listing accurate and gives future
handoffs a tracked home.
