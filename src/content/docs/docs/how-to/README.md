# How-to guides

No product how-to guide is currently admissible. Bitty has no released commands
or workflows, so this directory records only the category contract and empty
state.

## Admission criteria

A how-to guide solves one concrete task for named versions/platforms. It states
prerequisites, safe steps, expected result, verification, common failure, and
recovery. It links reference facts instead of reproducing entire APIs.

## Authority and status

How-to guides are verified procedures, not specifications or broad learning
paths. A guide cannot claim support beyond implementation/test evidence, and a
draft cannot turn an open design question into a default.

## Naming and maintenance

Use an action-oriented kebab-case name such as `configure-a-profile.md`. Retest
after affected behavior changes, state version limits, and pair deprecation with
replacement and redirect requirements.
