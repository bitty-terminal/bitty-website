# Interfaces

Index of the AI-core interface documents. Normative detail lives in the linked
pages; this index carries no duplicate normative prose.

## Admission criteria

A document belongs here when it defines the AI-core surface facing the terminal
platform: panel environment awareness, sanitized Agent View, environment-handle
semantics, or browser and agent panel integration. It links the architecture
dispositions it elaborates and includes security review where environment or
capability trust boundaries are involved.

## Authority and status

Every page here is a draft proposal. Draft text does not authorize shipped,
stable, normative, or compatibility-guaranteed behavior. Status meanings and the
normative authoring policy live in the
[documentation workflow](../docs/development/documentation-workflow.md); the
accepted [IPC and Agent RFC](../specifications/ipc-agent-rfc.md) overrides any
conflicting direction.
