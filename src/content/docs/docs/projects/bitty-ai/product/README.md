# Product

Index of the AI-core product scope documents. Normative detail lives in the
linked pages; this index carries no duplicate normative prose.

## Admission criteria

A document belongs here when it defines the first runtime increment, records the
vertical-slice pressure-test gaps, or registers the AI-core unresolved
questions with their feature prerequisites and review routing. It links the
architecture dispositions it depends on and preserves every question identifier.

## Authority and status

The pages here are draft scope and register records. Draft text does not authorize shipped,
stable, normative, or compatibility-guaranteed behavior. Status meanings and the
normative authoring policy live in the
[documentation workflow](../docs/development/documentation-workflow.md); the
accepted [IPC and Agent RFC](../specifications/ipc-agent-rfc.md) overrides any
conflicting direction.
