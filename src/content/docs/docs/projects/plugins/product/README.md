## Authority and status

Normative pages record required policy; accepted pages record reviewed
direction or maintained fact; draft pages are candidate work that
authorizes no release. Implementation claims require evidence from the
owning code repository. Shared cross-project governance stays in
[bitty-docs](https://github.com/bitty-terminal/bitty-docs) and is linked,
never copied.
