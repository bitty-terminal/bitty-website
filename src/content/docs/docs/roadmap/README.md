# Roadmap

Bitty has no committed release roadmap yet. The current [docs-first TODO](../../TODO.md)
tracks foundation work; it is not a promise of product dates or release scope.

## Admission criteria

A roadmap item links accepted requirements, dependencies, owner, success
evidence, and an explicit confidence or planning horizon. Dates and release
targets require accountable evidence rather than design enthusiasm.

## Authority and status

Roadmaps communicate sequencing and intent, not shipped behavior or contractual
availability. CarryCtx tasks are the execution record; requirements and
specifications remain the authority for what completion means.

## Naming and maintenance

Use `YYYY-QN-topic.md` for time-bounded plans or `now-next-later.md` for an
explicit horizon model. Review stale assumptions regularly, preserve material
scope changes, and link completed outcomes to release evidence.
