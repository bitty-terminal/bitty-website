## Evidence columns

| Column         | Meaning per RFC taxonomy                                                                                                                                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Risk           | Register ID R-001..R-022, severity and stage unchanged                                                                                                                                                                                     |
| P0-AC          | Linked testable criteria P0-AC-001..P0-AC-034; a risk is closable only when every linked criterion passes                                                                                                                                  |
| Implementation | Crate or module that owns the control at `be3bdb4`; presence alone is not evidence                                                                                                                                                         |
| Test           | Headless unit or integration harness that asserts the pass threshold; name the crate test file or suite                                                                                                                                    |
| CI             | Gating hygiene that must be green on every run: `just check` + `cargo check` / `cargo clippy -D warnings` / `cargo test --locked` + CodeQL + `actionlint` / `act -n`                                                                       |
| Adversarial    | Malformed, oversized, fuzz, timeout, scope-escalation, tamper or boundary suite that must fail closed with zero panics/hangs and no partial state                                                                                          |
| Audit          | `manual-audit` reviewer-signed artifact under `docs/security/audits/` or CarryCtx note that confirms the prose was checked against the surface; required for at least R-003, R-005, R-008, R-010, R-011, R-013, R-014, R-018, R-019, R-021 |
| State          | `Open` until all linked P0-AC pass per their verification method and the auditor records `Mitigated`; `Accepted` additionally requires a time-bounded CarryCtx decision                                                                    |

`ci-gate` evidence (advisory, source, license, bans, lint) is cited via the
`cargo vet` / `cargo audit` / `cargo deny` workflow run URL when the gate
exists; for `bitty-docs` the gate is `just check` plus `actionlint` and
`act -n` DRYRUN as defined in the justfile.

## Review gates and lifecycle

Per [risk evidence RFC](../specifications/risk-evidence-rfc.md) RS-1..RS-7:

- `Open -> Mitigated` requires, for the risk's linked P0-AC set, all of
  unit/integration green, adversarial corpus zero crashes/hangs, negative/limit
  coverage exhaustive, budget/attribution enforcement observable, `just check` and
  `ci-gate` green, secret/scope assertions where cited, manual-audit report where
  cited, and safe-mode re-verified where intersecting R-009/R-007/R-015/R-022.
- `Mitigated -> Accepted` adds a time-bounded CarryCtx decision with owner,
  rationale, expiry and residual-risk follow-up; it never weakens a normative
  control.
- `Reopening` occurs without a new decision on any regression in a linked suite,
  new fuzz finding, advisory, or mechanism change invalidating the cited hash or
  run.
- This Phase E matrix stays `Open` for 19 risks until the auditor records
  the review that moves a risk out of `Open`; `R-005`/`R-006`/`R-007` moved
  `Open -> Mitigated` at `bitty` `d4d75e9` (`5bdcdbd`/`0afc94d`/`d4d75e9`,
  Issues 137/138/139) per RS-1..RS-7 and PR #144/#145/#146 independent
  review. The 2026-09-07 FIND-0002 remediation wave (`ec95c5c..0cb244d`,
  head `1fc6294`) adds `Implemented`-only rows and moves nothing; each
  affected risk stays `Open` pending its auditor review. Presence of
  `bitty-vt`, `bitty-rich` `ImageStore`, `bitty-ipc`
  256 KiB framing with peer credentials, `bitty-lua`/`piccolo` and resolver at
  `be3bdb4` is `Implemented` evidence, not `Verified` closure. `R-004` remains
  `Open` at `bitty` `7a4ee41` per the 2026-08-31 clipboard audit, which
  explicitly does not authorize `Open -> Mitigated` due to residual
