# Shared ChatGPT conversation coverage

Two historical ChatGPT conversations with the architecture advisor are
provenance for this corpus. The interpretation rules in the first section apply
equally to both sources.

## First source: Terminal architecture design

- Title: `Terminal architecture design`
- Public source: [ChatGPT shared conversation](https://chatgpt.com/share/6a8d7652-9de0-83e9-9a6b-bdc54ff2f7d6)
- Coverage: 20 of 20 turns
- Role: historical design input and provenance

The shared conversation records early questions, preferences, and design
suggestions. It is **not implementation evidence**, a release record, or an
authority that overrides the maintained corpus. Assistant suggestions remain
candidates unless the user explicitly accepted them or a later canonical
document establishes a normative requirement. The local transcript in `tmp/`
is temporary source material and is intentionally not copied into this
repository.

## Coverage rule

Every source turn of the first conversation appears exactly once in its
matrix, and every recorded route item of the second conversation appears
exactly once in the route-item matrix. A turn or route item can map to several
canonical documents, but future edits should change the canonical document
first and then update this traceability record. New decisions belong in the
[decision register](../decisions/index.md), and unresolved work belongs in the
[open-question register](../decisions/open-questions.md).
