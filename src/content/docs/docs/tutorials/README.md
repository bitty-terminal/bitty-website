# Tutorials

No tutorial is available before a supported Bitty build and user workflow
exist. This index reserves a learning-oriented category without inventing
installation, commands, key bindings, or results.

## Admission criteria

A tutorial has a defined learner, prerequisites, outcome, complete tested
sequence, expected checkpoints, explanation, cleanup, and supported version. It
teaches a coherent path rather than listing unrelated features.

## Authority and status

Tutorials teach from verified guides and reference; they are not the authority
for API or configuration details. Draft tutorials cannot establish product
behavior and are not admitted merely to preview candidate designs.

## Naming and maintenance

Use `NN-topic.md` when ordering is meaningful, otherwise a stable kebab-case
topic. Test the full path for each supported release and update or deprecate it
when prerequisites, UI, commands, or outcomes change.
