# a11y (native extension)

The candidate accessibility adapter: a headless backend plus a stable host seam (`SnapshotHost` with `Adapter::ingest_host` / `Adapter::expose_to`) that ingests snapshots through `SnapshotBuilder` (`bitty-a11y` README; `src/adapter.rs`, `src/host.rs`, `src/snapshot.rs`).

- Source checkout: `$BITTY_WORKSPACE/bitty-a11y` ([github.com/bitty-terminal/bitty-a11y](https://github.com/bitty-terminal/bitty-a11y))
- Crate: `bitty-a11y` (library, `src/lib.rs`; zero dependencies, `#![forbid(unsafe_code)]`)
- Maturity: implemented-only, not independently verified; Core follow-up (retiring `bitty-ui/src/a11y.rs` onto this seam) is pending.

## Lua / host surface

This crate exposes no direct `bitty.*` Lua namespace. It is Core-consumed mechanism: the adapter ingests terminal snapshots and exposes them to assistive backends. Lua plugins never call it directly.

## Minimal config

Native extensions take no per-extension user config file. Verify staging only:

```bash
bitty extension list
```
